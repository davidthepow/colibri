# Juego del Colibrí

Juego web estático preparado para ratón, pantallas táctiles y despliegue en Vercel.

## Desarrollo local

Puedes abrir `index.html` directamente o servir la carpeta con cualquier servidor estático, por ejemplo:

```bash
npx serve .
```

## Despliegue en Vercel

Importa esta carpeta o repositorio en Vercel. No necesita framework, comando de build ni directorio de salida: Vercel publicará `index.html` como sitio estático.
